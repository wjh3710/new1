향후 백엔드 API 연동 구조 & 명세 가이드

현재 프론트엔드 모듈은 아래 REST API 명세와 1:1 호환되도록 설계되어 있습니다.

권한 및 화면 분리 아키텍처

• 인증 (Auth): 사용자가 로그인하면 백엔드는 JWT Access Token과 User Object { role: 'admin' | 'user', username, ... }를 반환합니다.
• 라우팅 분기: role === 'admin'이면 즉시 관리자 대시보드(#view-admin)가 렌더링되고, role === 'user'이면 메인 투표 화면이 열립니다.
• 데이터 통신: 현재 프론트엔드의 DataService 및 StatsService가 백엔드 API 호출로 즉시 치환되도록 모듈화되어 있습니다.

주요 REST API 엔드포인트 명세 (준비 완료)
Method Endpoint 권한 설명
POST /api/v1/auth/login All 사용자 및 관리자 계정 로그인, JWT 발급
GET /api/v1/tournaments All 투표 목록 및 후보 맛집(네이버 링크 포함) 조회
POST/PUT /api/v1/tournaments Admin 관리자: 투표 생성 및 수정
POST/PUT /api/v1/candidates Admin 관리자: 맛집 추가 및 정보(이름, 메뉴, 사진, 네이버링크) 수정
POST /api/v1/votes/record User 지역별 식당 픽 및 메뉴 추가 투표 기록
GET /api/v1/admin/stats Admin 관리자: 지역별 누적 득표 및 일별 투표 현황 조회
